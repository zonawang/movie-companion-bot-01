# 第一個影城工具：松菸誠品

這一版把「影城正在放什麼」與「電影在講什麼」串起來，繼續以 ADK 的工具呼叫為主軸。

## 在 LINE 試這幾句

- 「今晚松菸誠品有哪些電影和場次？」
- 「明天松菸誠品有哪些片？」
- 「10 月 28 日誠品晚上六點後有什麼電影？」
- 接著問：「進擊的鼓手在講什麼？兩句話，不劇透。」

第一個問題應呼叫 `cinema_schedule`，追問電影介紹則呼叫 `search_movies`。目前可跨對話追問電影介紹，沒有自動訂票或選位功能。

## 分工

1. **Gemini + ADK** 理解影城、日期與時段，選擇工具並帶入參數。
2. **`CinemaSource`** 讀取[誠品官方時刻表](https://meet.eslite.com/tw/tc/gallery/movieschedule/201803020001)，解析片名、日期與場次。
3. **一般程式** 使用台灣時間篩選、處理跨年，直接輸出可核對的時間清單。
4. **TMDB 工具** 在需要時補電影簡介與使用者評論連結。

單純場次查詢採程式格式輸出，不使用模型改寫後的時間。電影介紹可以由模型摘要，場次來源與電影資料來源各自標示。

## 資料來源與限制

- 讀取官方公開 HTML 時刻表，並非影城公開 API。只整理片名、場次等必要資訊與官方連結，不下載海報或複製完整電影介紹。
- 回覆附實際的官方更新時間、讀取時間與[官方訂票入口](https://arthouse.eslite.com/visAgreement.aspx)。
- 共用 5 分鐘快取並合併同時請求，失敗後限制重試頻率；不是逐秒更新的售票資訊。
- 官網可能移除已開演場次；「目前公告」不保證包含當天所有曾放映的場次。
- 日期未公告時回覆「尚未查到公告」；時段篩選後沒有場次時回覆「沒有符合時段的公告場次」，不推論影城停映或票已售完。
- 目前只支援松菸誠品。其他影城提供官網入口；沒有即時剩餘座位、票價或代訂票功能。
- 官網連線失敗或結構變更時，回覆無法讀取並附官方入口，不用舊資料冒充現在的場次。

## 開發驗證

```bash
npm test
npm run smoke:cinema
```

`smoke:cinema` 真正使用 Gemini、誠品公開時刻表與 TMDB，會消耗模型 API 額度；使用記憶體資料庫，不傳送 LINE 訊息、不修改正式票根。

單元測試使用自製 HTML，涵蓋日期與時段、跨年、多場次、未公告、格式變動、快取與 ADK 工具呼叫；測試片名與時間不代表官方場次。
